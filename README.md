# OIBSIP_domain_taskno.4
Email Spam Detection with Machine Learning is a text classification project that identifies whether an email is spam or not spam (ham). Using machine learning and natural language processing techniques, the model is trained on labeled email data to automatically detect unwanted, fraudulent, or phishing emails

Spam emails are unwanted messages that often contain advertisements, scams, or phishing content. This project uses machine learning techniques to build an email spam detection system that classifies emails as **Spam** or **Not Spam (Ham)** based on their text content.

## what my project does??
- Understand the basics of text classification
- Preprocess email text data
- Build a machine learning model for spam detection
- Classify emails into spam and non-spam categories
- Evaluate model accuracy and performance

## Datasets used are: 
- Contains labeled email messages
- Two categories:
  - Spam
  - Ham (Not Spam)
- Dataset includes email text content and labels
